Break the DroneSMS MVP into small beginner-friendly build phases.

Each phase should include:

* Phase name
* Goal
* What will be built
* What files or folders may be changed
* How I can visually confirm it worked
* What should not be built yet
* When to stop and ask me before continuing

Keep the language clear enough for a non-developer founder to understand.

Do not start building the app yet. Only create the build phases document.
